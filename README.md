
# DooR DasH: Scare vs Laugh Touchdown 👾

## About the Project
DooR DasH is a competitive board game developed using Java and inspired by the world of Monsters, Inc.

The game features two competing teams: SCARERS and LAUGHERS. Players navigate a 100-cell board, collect energy, use special abilities, draw cards, and overcome obstacles to reach Boo's Door.

The main objective is to reach the final cell with at least 1,000 energy.

## Game Features
- 100-cell board arranged in a zigzag pattern.
- Two competing teams: SCARERS and LAUGHERS.
- Eight unique monsters with different abilities and starting energy.
- Turn-based gameplay with dice rolling.
- Energy collection and management system.
- Special cells, including:
  - Conveyor Belts
  - Contamination Socks
  - Monster Cells
  - Card Cells
- 25 shuffled cards with different effects.
- Special monster powerups and abilities.
- Interactive graphical user interface.
